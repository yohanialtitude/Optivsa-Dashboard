## Firebase setup

The app uses Firebase Authentication and Cloud Firestore through `src/lib/firebase.ts`.

In the Firebase console for project `altitude1-b56fa`:

1. Enable Email/Password and Google providers under Authentication.
2. Create a Cloud Firestore database.
3. Add your local development domain to Authentication > Settings > Authorized domains.

New accounts create a `users/{uid}` document in Firestore. Firestore rules should require
authenticated access and restrict user profile reads and writes to the owning `uid` before
using this app beyond local development.
